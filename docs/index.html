What you get

File Management

Drag-and-drop uploads, version history, tagging, preview for images, PDFs, video and audio, plus a live dashboard.

Secure Sharing

Public share links with optional passwords, expiration dates, one-time downloads, and instant revocation.

Multi-User & Roles

Role-based access control, per-role storage quotas, speed limits, admin approval, and activity logs.

Notes & Themes

Personal notes with categories, full-text search, light/dark mode, and full color customization.

Easy Install

Automated installers for Windows, macOS, and Linux. Docker support included. SQLite works out of the box.

Security

CSRF protection, secure sessions, bcrypt password hashing, rate limiting, IP blocking, and path traversal prevention.
